# Hotel Reservation System (Java OOP Mini-Project)

Problem: Java console application to manage rooms, customers, reservations, cancellations and billing.

Rules: room must be available to book; availability updates on booking/cancel; premium customers get a tier
discount (5/10/15%) and loyalty points; bills include 12% GST; every booking links to one room and one customer.

Run: import into Eclipse (JDK 17+) and run com.hotel.main.Main.
Tests: run com.hotel.test.HotelSystemTest (17 run, 17 passed, 0 failed).
